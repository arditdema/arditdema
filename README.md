## Featured Project

### Wazuh SOC Home Lab

A documented SOC lab built from scratch: Wazuh SIEM and Sysmon telemetry on a Windows 10 endpoint. The repository contains four incident-response triage reports and two custom Wazuh detection rules mapped to MITRE ATT&CK T1053.005.

**Highlights:**
- Triage based on signatures, file hashes, parent processes, and Sysmon event chains
- Detection gap confirmed through Atomic Red Team simulation, then fixed with custom rules 100100 and 100101
- Reporting that states limitations openly and gives narrow tuning recommendations

Repository: [github.com/arditdema/wazuh-soc-lab](https://github.com/arditdema/wazuh-soc-lab)
